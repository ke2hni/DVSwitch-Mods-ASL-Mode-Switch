Standalone ASL mode-switch repair test procedure

Run the patcher regression test from the extracted package directory:

PYTHONDONTWRITEBYTECODE=1 python3 tests/test-dvswitch-asl-mode-switch-patcher.py

On a test node, check compatibility without modifying the installed script:

sudo ./repair-dvswitch-asl-mode-switch.sh --check

If the check passes, install on pi4test first:

sudo ./repair-dvswitch-asl-mode-switch.sh --install

Then switch from ASL to P25, NXDN, DMR, D-Star, YSF, and STFU as configured,
using the normal terminal command and dashboard controls. Verify that the
reported mode and dashboard state follow each selection. The script change
does not require a service restart or reboot.

After pi4test passes, repeat on pi5test and test3040. Do not install on a
production node without explicit authorization.

To restore the pre-install script, use the backup name printed by --install:

sudo ./repair-dvswitch-asl-mode-switch.sh --restore install-YYYYMMDD-HHMMSS
